# YouTube Music Selector

Android のローカルフォルダにある YouTube 視聴履歴由来の JSONL を、1件ずつ安全に分類するオフライン対応PWAです。データをサーバーへ送信せず、外部CDN・解析・広告も使用しません。

## 必要環境と起動

Node.js 20以降で次を実行します。

```sh
npm install
npm run dev
```

本番成果物は `npm run build` で `dist/` に生成されます。静的ホスティング（GitHub Pages、Cloudflare Pages等）で **HTTPS** 配信してください。`dist/` をHTTPSのサイトルートに配置する構成を想定しています。

## Androidでの利用

1. HTTPSで公開されたページを、Android版Chromeなど File System Access API 対応ブラウザで開きます。
2. ブラウザのメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
3. 最初の起動時に「データフォルダを選択」を押し、4つのJSONLを置いたフォルダを選択し、読み書き権限を許可します。
4. キャッシュ完了後に一度オンラインで表示できることを確認し、機内モードでアプリを再起動して確認します。

フォルダには次の4ファイルが必要です。不足時だけ、確認ダイアログから空ファイルを作成できます。既存ファイルは初期化しません。

```text
likely.jsonl
possible.jsonl
unknown.jsonl
excluded.jsonl
```

## 操作と安全性

- 分類ボタンは移動先へ保存・検証してから移動元を削除します。途中で失敗すれば可能な範囲で元に戻し、正常終了として扱いません。
- 読み込み後に他アプリが編集していた場合、指紋比較により上書きを止めます。再読み込みして確認してください。
- 同じ `video_id` の重複、破損したJSONL、権限不足は書き込みを中断します。
- 「このまま次へ」は同じファイルを選んだ場合のスキップです。書き込みません。
- 「直前の移動を取り消す」は最大20件を端末内IndexedDBに保持します。
- チャンネル判定は `channel_labels.json` にのみ保存し、作品のJSONオブジェクトは変更しません。
- 「バックアップZIP」は4つのJSONLと存在する `channel_labels.json` を端末へダウンロードします。

## テスト

```sh
npm test
npm run build
```

テストはJSONLの空行・破損行、全プロパティの保持、重複検出、移動計画を検証します。実機のフォルダ権限、PWAインストール、オフライン起動は対象ブラウザ・端末上で確認してください。

## 制約

- File System Access APIがないブラウザ（例: 多くのiOSブラウザ）では、既存ファイルを直接更新できません。
- 複数ファイルへの完全な原子書き込みはブラウザAPIが提供しません。実装は検証・ロールバック・バックアップで影響を抑えます。重要データは操作前にもバックアップしてください。
- YouTubeリンクはネットワーク接続時だけ開けます。分類画面とローカル処理はオフラインで利用できます。
