# 利用ガイド

このアプリは、YouTube視聴履歴のJSONLを端末内だけで分類します。データはサーバーへ送られません。

## 開発版を起動する

Node.js 20以降を用意して、プロジェクトのフォルダで次を実行します。

```powershell
npm.cmd install
npm.cmd run dev
```

表示されたアドレスをブラウザで開きます。PowerShellの設定によって `npm` が動かない場合があるため、`npm.cmd` を使っています。

## テストとビルド

```powershell
npm.cmd run test
npm.cmd run build
```

テストが失敗した場合は、表示された日本語のテスト名をそのまま共有してください。履歴データの中身は共有しないでください。

## Androidで使う前に

1. 大切なJSONLファイルを、アプリとは別の場所へコピーしてバックアップします。
2. HTTPSで公開したアプリを対応ブラウザで開きます。
3. 「データフォルダを選択」を押して、4つのJSONLがあるフォルダを選びます。
4. 最初はコピーしたデータで、分類、Undo、バックアップ、オフライン起動を確認します。

## 実データの形式調査

実データは必ずコピーしてから、コピーを置いたフォルダに対して実行します。

```powershell
node tools/inspect-data.js "C:\\調査用コピーのフォルダ"
```

結果には件数や形式だけが表示され、動画名・URL・チャンネル名は表示されません。
